# Meu Ledger 📓

Aplicativo de controle financeiro pessoal focado em organização de orçamento, evolução patrimonial e metas de investimentos, com base na lógica de partidas dobradas.

## 🛠 Tech Stack
- **Framework:** Next.js (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS + Shadcn UI
- **Banco de Dados:** Neon DB (PostgreSQL) + Prisma ORM
- **Autenticação:** Better Auth
